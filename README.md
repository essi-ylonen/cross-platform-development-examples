# Cross-Platform Development Examples
Example codes for the Cross-Platform Development course at HAMK
## Topics

- Custom components
- Passing props
- State variables + form handling and handling user input
- FlatList with custom component
- FlatList with an Insert Modal
- React Native + Node.js REST API Example
- CRUD Example
- Stack navigation
- Drawer navigation
- SQLite, local database and table creation
- SQLite, adding and reading data
- Student interactions (dragging, deleting by swipe + checkboxes and radio buttons)

This Topics list will be updated during the course.
 
The examples are intentionally simple and designed to support classroom demonstrations.
