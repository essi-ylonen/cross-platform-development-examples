# test-students-stack

Cross-Platform Development course example.

This example demonstrates **Stack Navigation** using Expo Router and React Native. The application displays a list of students retrieved from a REST API and allows users to navigate to a separate details screen for an individual student.

The backend used in this example is:

- rest-api-students2 (Node.js + Express)

## Learning goals

After studying this example, you should be able to:

- Understand the concept of Stack Navigation
- Use Expo Router for file-based routing
- Create multiple screens in a React Native application
- Navigate between screens using `router.push()`
- Pass route parameters between screens
- Read route parameters using `useLocalSearchParams()`
- Fetch data from a REST API
- Display student details on a separate screen
